iT1DXpert — WhatsApp Integration System Architecture

System Target: Deterministic, zero-LLM-cost patient health metric and clinical document ingestion via Meta WhatsApp Business Cloud API, Node.js/Express, Prisma ORM, PostgreSQL, and S3-compatible Object Storage.

1. Meta WhatsApp Business Account (WABA) Configuration

  • Meta Developer Portal: Create a Business App at developers.facebook.com and add the WhatsApp product.
  • Phone Registration: Attach a clean dedicated phone number not registered to standard WhatsApp accounts and verify OTP.
  • Permanent System User Token: Generate a permanent System User Token under Meta Business Settings with whatsapp_business_messaging and whatsapp_business_management scopes.
  • Webhook Subscription: Subscribe callback URL https://api.domain.com/api/webhooks/whatsapp to the messages field with verify token WHATSAPP_VERIFY_TOKEN.
